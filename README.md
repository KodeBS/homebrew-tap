# KodeBS Homebrew tap

```bash
brew install --cask kodebs/tap/kodebs-homelab
```

Updates arrive with `brew upgrade`, or from the app's *Settings → Updates → Install*.

**KodeBS Homelab for macOS** — Apple Silicon only. The app is signed ad hoc, not
notarized; the cask clears the quarantine flag after installing so it opens normally.

The cask and the `.dmg` on this repository's releases are published by the
release workflow of KodeBS/homelab. Do not edit `Casks/` by hand — the next
release overwrites it.
